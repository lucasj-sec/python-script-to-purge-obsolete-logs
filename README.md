# Disk Usage Checker

Script Python que verifica o uso de disco em um caminho configurado e, se ultrapassar um limite definido, oferece a opção de apagar logs com mais de 3 meses.

## Uso
python payload.py

## Aprendizados
- Corrigido path incorreto (/var/logs → /var/log)
- Adicionado bloco `if __name__ == "__main__":` para garantir a execução da função
